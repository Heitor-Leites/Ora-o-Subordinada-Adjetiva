# ⚔️ A Jornada da Gramática

**Um jogo educativo de plataforma 2D para aprender gramática de forma interativa!**

A Jornada da Gramática é um jogo desenvolvido em HTML5, CSS e JavaScript, que combina exploração, desafios e conhecimentos de Língua Portuguesa.

Em uma aventura por diferentes cenários, o jogador precisa superar obstáculos e responder a perguntas sobre **orações subordinadas adjetivas**, colocando seus conhecimentos à prova.

## 🌎 Sobre o jogo

A aventura acontece em um mundo de fantasia dividido em quatro biomas:

- 🌳 **Floresta Encantada**
- 🏜️ **Deserto Dourado**
- ❄️ **Montanhas Geladas**
- 🌋 **Reino Vulcânico**

Cada ambiente faz parte de uma jornada de exploração e aprendizagem.

## 🎮 Funcionalidades

- Movimentação e exploração em plataforma 2D.
- Sistema de salto e salto duplo.
- Mecânica de voo.
- Obstáculos e plataformas.
- Checkpoints com desafios de gramática.
- Sistema de pontuação.
- Controles para computador e dispositivos móveis.
- Cenários com diferentes biomas.

## 🕹️ Controles

| Ação | Comando |
|---|---|
| Movimentar para a esquerda | A ou ← |
| Movimentar para a direita | D ou → |
| Pular | Barra de espaço |
| Voar | Dois cliques rápidos |

*Dispositivos móveis contam com controles na tela.*

## 📚 Conteúdo educacional

O foco principal do jogo é o estudo das **orações subordinadas adjetivas**, abordando conhecimentos gramaticais por meio de perguntas e desafios durante a aventura.

## 🚀 Como jogar

Você pode jogar diretamente pelo navegador, sem precisar instalar programas.

**Acesse:** https://oracaosubordinadaadjetiva.netlify.app

Também é possível executar o projeto localmente:

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Comece sua aventura!

## 🛠️ Tecnologias utilizadas

- HTML5

Demonstrar como a tecnologia e a gamificação podem contribuir para o processo de aprendizagem, transformando conteúdos escolares em experiências interativas.
